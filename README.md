# Lifestyle Navigator 🌿💻

Hi, I'm Prakhar! This project is a curated lifestyle web directory designed to help you discover helpful and trustworthy websites that can improve different areas of your daily life.

Whether you're looking for fitness guidance, relationship advice, entertainment options, or general well-being tips, this site connects you to quality online resources—all in one place.

## 🌟 Features

- 🔍 **Browse by Category**: Health, Relationships, Self-Growth, Entertainment (TV shows, movies), and more.
- ✅ **Curated Recommendations**: Only useful, reliable, and user-friendly websites.
- 🧠 **Simple UI**: Easy to navigate and mobile-friendly interface.
- 🆕 **Regular Updates**: I plan to keep adding new categories and sites based on user feedback.

## 📌 Why I Built This

I often find myself digging through multiple blogs, forums, or articles to find something useful. 
So I decided to create a hub where anyone can easily find quality lifestyle content without the hassle of searching endlessly.
